# OA 答复分析模块 — 用户操作指南

> 面向研发用户的操作文档。适用于 InnoForge v0.9.0+。
>
> 本模块帮助专利申请人/代理师答复审查意见通知书（OA），覆盖从分析到生成答复书全流程。

---

## 一、功能概览

OA 模块位于导航栏「OA答复分析」页面，提供以下能力：

| 能力 | 说明 |
|---|---|
| **OA 分析** | 将审查意见 + 我的专利 + 对比文献送入 AI，按三步法进行创造性分析 |
| **AI 讨论** | 基于分析结果与 AI 多轮对话，深入讨论答辩策略 |
| **答复书生成** | 根据分析 + 讨论结果，生成可提交的正式答复书 |
| **答复书导出** | 导出为 Word 文档，可直接用于提交 |
| **权项修改检查** | 对比修改后权利要求与原文，检测超范围风险 |
| **对比文献管理** | 手动输入或从本地专利库查找对比文献 |

---

## 二、操作流程

### 2.1 选择答复类型

页面顶部有三类 OA 类型可选：

| 类型 | 适用场景 |
|---|---|
| **一审/二审答复** | 第一次审查意见通知书或第二次审查意见通知书的答复 |
| **非正常申请答复** | 非正常申请相关通知的答复 |
| **驳回后复审** | 收到驳回决定后提出复审请求 |

> **重要**：类型决定 AI 分析的 prompt 结构和答复书模板。驳回后复审使用六角度结构化框架（详见 §4），请务必选对。

### 2.2 填写我的专利（本申请）

三种输入方式：
1. **手动输入专利号**：在输入框填入专利号或内部 ID，点击「查库」从本地数据库查找
2. **上传文件**：点击📎上传 PDF/DOCX/TXT 文件，系统自动提取文字
3. **直接粘贴**：在文本框粘贴权利要求书 + 说明书内容

> 提示：AI 分析质量与输入材料完整度直接相关。建议至少包含完整权利要求书和说明书具体实施方式段。

### 2.3 填写审查意见通知书

两种输入方式：
1. **上传 OA PDF**：系统自动提取文字（多层提取策略：pdf-extract → pdftotext → PyMuPDF → OCR）
2. **粘贴全文**：直接粘贴审查意见通知书文字内容

> 如果 OA 文件是扫描件，系统会自动尝试 OCR 识别。OCR 可能需要较长时间，请耐心等待。

### 2.4 添加对比文献

点击「+ 添加对比文献」可添加多篇对比文件：

- 每篇可手动输入专利号 + 点击「查库」从本地库查找全文
- 也可上传对比文件（PDF/DOCX）
- 对比文献信息会送入 AI 用于三步法分析

> v0.9.0+：驳回后复审模式下，系统可从 OA 文本自动抽取对比文件公开号并查询全文（UA1 功能）。

### 2.5 选择分析深度

| 深度 | 说明 | 耗时 |
|---|---|---|
| **浅度（shallow）** | 快速概要分析，适合初步评估 | 约 10-30 秒 |
| **中度（medium）** | 标准三步法分析，含区别特征矩阵和答辩建议 | 约 30-60 秒 |
| **深度（deep）** | 完整六角度结构化分析 + 事实核查 + 出处锚点 | 约 60-120 秒 |

> 驳回后复审 + 深度模式使用六角度框架（事实对照 → 法条适用 → 技术效果 → 策略权衡树 → 程序适配 → 说服结构），详见 §4。

### 2.6 开始分析

点击「开始分析」按钮，AI 将：
1. 按选定深度和类型生成分析报告
2. 分析结果分多部分显示（权项分析 → 审查逻辑 → 特征对比 → 逐条反驳 → 答复草稿）
3. 分析完成后自动进入讨论区

---

## 三、AI 讨论

分析完成后，可在讨论区与 AI 多轮对话：

### 3.1 基本操作

- 在输入框输入问题，点击「发送」
- AI 基于当前 OA 上下文（分析结果 + 原始材料）回答
- 点击「■ 停止」可中断 AI 生成

### 3.2 论点提取

点击「📋 论点提取」按钮，AI 从讨论记录中提取结构化论点：
- 每个论点标注采纳风险（Has Risk / Adopt / Reject）
- 可据此决定哪些论点写入正式答复书

### 3.3 导出讨论

- **📝 AI 总结结论**：AI 汇总讨论要点，生成结论摘要
- **📥 导出完整讨论记录**：导出全部讨论内容为文件

### 3.4 历史讨论

- 讨论自动保存，可从历史列表恢复
- 点击「新讨论」开始全新对话
- 点击「继续」恢复历史讨论

### 3.5 导入讨论

点击「导入」可导入外部讨论记录，用于跨会话延续工作。

## 四、驳回后复审 — 六角度结构化框架

选择「驳回后复审」+「深度」模式时，AI 按以下六角度强制输出：

### 角度一：事实对照
- 驳回决定逐段拆解，明确每段认定的技术事实
- 权利要求逐项特征矩阵
- 对比文件公开/未公开特征映射表

### 角度二：法条适用
- 三步法每一步逐一验真（成立/不成立/部分成立）
- 每步须有明确结论，不得含糊

### 角度三：技术效果
- 区别特征带来的技术效果逐条列举
- 标注原说明书是否记载该效果（是/否 + 段落号）
- 与驳回决定认定的效果做对比

### 角度四：策略权衡树
- 至少两条论证路径（主路径 + 备选路径）
- 每条标注：胜率评估、风险点、依赖前提
- 路径间衔接关系

### 角度五：程序适配
- 复审程序与实审程序的关键差异
- 本案在复审程序中的特殊注意事项

### 角度六：说服结构
- 论证编排建议
- 预判合议组质疑（2-3 个）及预先回应

### 出处锚点纪律

所有事实断言必须带出处锚点，格式：`【依据：<出处类型>：<定位信息>】`

合法出处类型：
- 驳回决定：第X段 / 第X页第X段
- 权利要求：权项X / 权项X第X特征
- 说明书：第X段 / 第X段第X行
- 说明书附图：图X / 图X中标记Y
- 对比文件：DX第X段 / DX第X页 / DX权利要求X
- 法条：专利法第X条 / 审查指南第X章第X节

> 无法溯源的断言会降级为【需申请人确认】或被删除。这是零幻觉可审计标准。

## 五、答复书生成与导出

### 5.1 生成答复书

分析 + 讨论确认后，点击「生成答复书」按钮：
- AI 根据分析结果和讨论结论生成正式答复书
- 答复书格式按 OA 类型自动选择模板
- 驳回后复审使用复审请求书四部分结构（复审请求范围 → 逐项消除缺陷论证 → 修改说明 → 提交前清单）

### 5.2 提交前清单

驳回后复审的答复书末尾自动附「提交前清单」：

- [ ] 核对申请号、发明名称、驳回决定发文日
- [ ] 确认复审请求范围（全部驳回 / 部分驳回）
- [ ] 逐条核对论证中的出处锚点是否准确
- [ ] 如有修改，确认修改不超范围（对照 A33 检查结果）
- [ ] 确认答复期限（收到驳回决定之日起三个月内）
- [ ] 检查附件清单（修改后的权利要求书、其他附件）

### 5.3 导出 Word

点击「导出」将答复书导出为 Word 文档，可直接用于提交。

---

## 六、权项修改检查

### 6.1 修改后权利要求

在「✏️ 修改后权利要求」区域填入修改后的权利要求文本。

### 6.2 超范围检查

点击「🔍 检查超范围」按钮，系统对比修改后权项与原权利要求书 + 说明书：
- 检测引入说明书未记载的新术语/新特征
- 标注每处超范围风险
- 结构化输出：权项号 → 修改内容 → 风险等级 → 依据

### 6.3 权项 Diff 可视化

点击「📊 Show Diff」查看修改前后权项的逐字对比差异。

---

## 七、期限提醒

填写 OA 发文日后，系统自动计算答复期限：
- 一审/二审：收到之日起四个月内
- 驳回后复审：收到驳回决定之日起三个月内

> 提示：期限计算仅供参考，请以官方通知书载明的期限为准。

## 八、AI 调用说明

### 8.1 支持的 AI 服务商

InnoForge 内置支持 10 家 AI 服务商，在设置页可切换：
- DeepSeek（推荐，性价比高）
- 智谱 GLM
- Moonshot Kimi
- Google Gemini
- OpenAI GPT
- Anthropic Claude
- 及其他 OpenAI 兼容接口

### 8.2 分析质量建议

- **输入完整材料**：权利要求书 + 说明书具体实施方式 + 审查意见全文
- **使用深度模式**：重要案件建议用深度模式，六角度框架覆盖更全面
- **善用讨论功能**：多轮讨论可深入挖掘答辩角度
- **检查出处锚点**：深度模式下每个事实断言带出处，便于核验

### 8.3 注意事项

- AI 产出是**起草辅助**，提交前请人工核对事实与程序信息
- 对比文献全文抓取依赖免费源（Google Patents），可能受反爬限制
- 分析过程中请勿关闭页面，否则需重新开始

## 九、常见问题

**Q: 上传 PDF 后文字提取失败？**
A: 系统依次尝试 6 种提取方式（pdf-extract → pdftotext → PyMuPDF → Tesseract OCR → Umi-OCR → AI 视觉）。如全部失败，建议：1) 上传可编辑的文本文件 2) 直接粘贴文字内容。

**Q: 分析结果中出现「需申请人确认」？**
A: 这是零幻觉纪律的体现——AI 对无法从材料溯源的断言不做猜测，标注后由人工确认。请核对原始材料后决定保留或删除。

**Q: 驳回后复审和一审答复有什么区别？**
A: 驳回后复审使用六角度结构化框架 + 复审请求书模板（四部分结构 + 提交前清单），分析更深入；一审答复使用标准三步法分析 + 意见陈述书模板。

**Q: 对比文献查库找不到？**
A: 本地库只包含已检索入库的专利。如未入库，可手动粘贴对比文献内容，或先在搜索页检索入库后再回来查库。

**Q: 讨论记录会丢失吗？**
A: 不会。讨论自动保存在浏览器 localStorage，可从历史列表恢复。也可导出讨论记录备份。
