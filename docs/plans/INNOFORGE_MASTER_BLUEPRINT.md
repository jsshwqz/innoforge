## 一、 仓库规约体系的 4 大病灶诊断（为什么 Agent 越跑越乱）

核查 `origin/main` 真实的 `AGENTS.md`、`CLAUDE.md`、`docs/feedback.md`、`docs/errors.md` 与 `tests/rectification_order_present.rs` 后，发现真正让 AI 混乱的 4 个根因：

| 病灶 | 实盘证据 | 公司级根治方案 |
| :--- | :--- | :--- |
| **1. `AGENTS.md` 与 `CLAUDE.md` 双份漂移自相矛盾** | `CLAUDE.md` 还写着“路由必须同时注册到 `main.rs` 和 `lib.rs`”、“禁止提交 `package.json`”、甚至挂着 `gitee.com` 链接；与 `AGENTS.md` 严重打架。 | **彻底消灭双副本**：以新版 `AGENTS.md` 为唯一权威，`CLAUDE.md` 精简为 8 行指向入口（仅保留 `2026-10-27 整顿令` 守卫标记）。 |
| **2. 已结项的“三周整顿令”压在顶部误导 AI** | `AGENTS.md` §〇 仍写着“三周禁止：新检索/向量/成本基建；#78 暂停”，新 Agent 读完直接懵掉。而 `tests/rectification_order_present.rs` 其实**只检查文件里包含字符串 `2026-10-27 整顿令`**。 | 将 §〇 压缩为 3 行「历史令归档声明」，**100% 通过 CI 守卫**，同时把永久精华（实证、不自嗨、案件数据隔离）正式升格进总宪章。 |
| **3. 复盘沦为“79 条无人阅读的流水账”** | `docs/errors.md` 停在 #79（11 月 15 日），`docs/feedback.md` 停在 11 月 8 日；长篇日记被上下文截断，AI 既不看旧坑也不写新坑。 | 推行**三层防再犯机制**：① 能写测试的进 `tests/`（机器拦截）；② 模块禁区写进 `.rs` 顶部 3 行 `//!`（就近撞脸）；③ 旧 #1–#79 归档至 `docs/archive/errors-history-1-79.md`，`docs/errors.md` 永远只保留 **Top-15 极简活索引**，每版收尾强制输出「本轮复盘沉淀」。 |
| **4. 缺少面向 AI 的效率底座** | 每次改功能 AI 要盲搜几十个文件、动辄苦等 16 分钟全量 E2E，导致慢且易出错。 | 新增 80 行极简 **`docs/CODE_MAP.md`**（能力 → 唯一入口文件 → 秒级定向单测命令），建立「秒级单测 → 本地全检 → 云端 E2E」三级验证阶梯。 |

## 二、 超级 AI 视角：产品功能全局重整（从“堆模块”回归“四大核心工作流”）

跳出以前零散口述的功能点，把 InnoForge 已经建成和计划建设的所有能力，严格按**「检索员 / 技术分析师 / 专利代理师」**三大角色重新归位，形成清晰、零臃肿的 **4 大主干工作流**，把偏离定位的边缘模块全部果断剥离：

| 核心工作流 | 对应虚拟专家角色 | 现有已成型的扎实底座（保留打磨） | 当前真实断链 / 必须补齐的硬伤 | 明确剥离/不做的伪需求 |
| :--- | :--- | :--- | :--- | :--- |
| **工作流 1：全域查新与证据沉淀** | **检索员** | 多源检索链、AI Search P1–P3、OpenAlex 论文、DB `v25` `chunks_fts` + RRF 混合检索、法律状态与引文图谱 | ① `/api/search/vector` 前端断链 + `MB0b` 存量回填；<br>② IPC 子空间锚定 + `Semantic Scholar` + `PubMed` + `CRAAP` 五维评分 + 检索透明化面板。 | 砍掉 9 家服务商硬编码单价表（改保留 Token 计数与日度熔断）。 |
| **工作流 2：文档/附图深度解析（多模态底座）** | **检索员 + 分析师** | PDF 文本层提取、Umi-OCR 地址可配置、附图视觉标号拓扑 | ① **立即根治 `c0d8fdd` / PR #243 假附图提取**（禁止整本 PDF 转图或套 iframe 顶替，回归真实嵌入式图像/附图页提取）；<br>② 统一全仓 OCR 优先走 `Umi-OCR`（打通 `extraction.rs` 两张皮）；<br>③ `T2.5` 异步 SSE OCR + V-RAG 附图标号双向高亮与交底书标号一致性核查。 | 不做与专利/文献解析无关的通用文档编辑器。 |
| **工作流 3：研发推演与可信决策闭环** | **技术分析师** | 16 步创新验证流水线、特征卡、FreeCAD 3D 建模、沙箱 3 轮自修复、BOM Excel + 论文 LaTeX/Word 导出 | ① **`finalize.rs` 证据门禁真阻断**（消灭只打 warn 不拦决策）+ **清零剩余 6 处裸截断**；<br>② `ResearchState` 跨轮次读取 `excluded_paths` + 步骤级快照回滚 + 限次自动补搜；<br>③ 研发问题结构化拆解 + `Minimal Diff 2.0`。 | 砍掉纯 Rust 硬编码 5 类玩具物理算子、砍掉 PLC 代码生成与电气 SVG 画图（保留 BOM + IO 需求规格即可）。 |
| **工作流 4：专利确权、布局与 OA 实战** | **专利代理师** | OA 核验链（锚点/覆盖/禁词/提交前自检）、Stage D 强模型比对、三维矩阵 + 修订 `.docx`、批量 FTO、权要树 26.4 自检、多轮 OA 漂移 | ① 补齐第三类核心报告——**「专利代理师版 (`type=patent`)」**（Claim Chart + 攻守梯度权要树）；<br>② 统一四角色模型路由（快/强/看图/严格 JSON 校验），让商汤免费 1M 池、GLM-5.3 Flash、Gemini 与 Qwen 4 各司其职。 | 砍掉后端 `services/` 全局大搬家、前端大拆迁、P50/P95 云端监控面板、自动化假题库跑分台。 |
